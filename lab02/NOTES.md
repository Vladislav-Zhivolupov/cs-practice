Рабочая папка — это папка проекта, в которой Git отслеживает файлы и их изменения.



Индекс - это область, куда помещаются изменения, подготовленные для следующего коммита.



Коммит - это сохранённая в истории версия подготовленных изменений.



Git - это система контроля версий, работает с репозиторием локально.

GitHub - это онлайн-сервис для хранения Git-репозиториев и работы с ними.



Использованные команды:



git status - показывает текущее состояние рабочей папки и индекса.

git diff - показывает изменения, ещё не добавленые в индекс.

git diff --staged - показывает изменения, добавленные в индекс и подготовленные для коммита.







Ветки:

Ветка - это указатель на коммит в истории гит.

При создании нового коммита ветка перемещается на него.

Merge объединяет изменения в ветках.
